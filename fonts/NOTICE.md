# Fonts in this folder

`nastaliq-urdu.woff2` is a subset of **Noto Nastaliq Urdu** (© The Noto Project Authors),
licensed under the **SIL Open Font License 1.1** (https://openfontlicense.org).
It is generated from `fonts/source/NotoNastaliqUrdu-arabic-var.woff2` (the Arabic-script part of the
Google Fonts build, same licence) by `npm run fonts`
(`scripts/subset-nastaliq.mjs`). Rerun it whenever Urdu text in `content/` changes.
